02 End-to-End Field Workflow — the core business loop

Every record flows through this pipeline: unknown market → discovered candidate → qualified lead → opportunity → visited, evidenced, closed. All nine stages are live today.

1

Discover prospects GIS Analyst / Manager Live

Candidates enter from external sources or manual capture. Coordinates validated against Hyderabad bounds, auto-corrected if missing.

Discovery modulePOST /discovery-candidatesGIS validation status
2

Duplicate screening System Live

Fuzzy name/address matching flags duplicates against existing Leads and Accounts before anything pollutes the CRM.

duplicate_detection.pyPOST .../check-duplicates
3

Convert candidate → Lead Manager / Analyst Live

One click creates the Lead in Salesforce carrying validated coordinates, review notes and source metadata.

POST .../convert-to-leadLeads module
4

Auto territory assignment System Live

Managers draw boundaries on the GIS map; every new record is assigned by point-in-polygon test — no manual tagging.

Territories moduleleaflet-draw polygonsterritory_assignment_service
5

Qualify → Opportunity Sales Exec / Rep Live

Contact and qualification happen on the ground; converted Leads become Opportunities tracked through ten stages toward close.

Leads → Opportunities modulesFull edit capability
6

Plan & optimize the day's route Field Rep Live

Pick stops inside your territory; OpenRouteService computes real driving order, distance and time. Manager approves or rejects.

Routes moduleGET /routes/todayPending / Approved / Rejected
7

GPS geofence check-in / check-out Field Rep Live

Check-in accepted only within the customer geofence via device GPS; check-out records duration; visit reopens if not validated.

FieldVisits modulePOST /visitsWS broadcast → live dashboard
8

Capture evidence Field Rep Live

Photos, notes and documents attach to the visit and its Account/Lead with a validation status trail — proof of every meeting.

Evidence module/evidence/visit/{id}
9

Measure & act Leadership Live

Dashboard aggregates all nine modules — pipeline by status/source/month, visit outcomes, overdue accounts, route distance/time, territory activity — plus Executive Analytics. Notifications come from real backend events.

/dashboard/* (20+ aggregates)Recharts + PDF export

06 Realtime event flow

Write operations push instant updates to every open session — no refresh needed.

1 · Action happens

  • Rep checks in at a stop
  • Account created / updated

2 · Router broadcasts

  • salesforce_router → realtime.py
  • broadcast_event(type, payload)

3 · All clients update

  • /ws WebSocket fan-out
  • Dashboard counters & notification feed refresh live
